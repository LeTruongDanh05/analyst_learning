# Superstore Retail Sales & Profitability Analysis

## Project Objectives
- **Data Quality Management:** Clean, de-duplicate, and structure raw, unformatted retail data.
- **Cross-Table Data Enrichment:** Dynamically map and merge external regional metrics into the core dataset.
- **Descriptive Analytics:** Analyze performance across segmented customer groups and geographic boundaries to answer critical "What happened?" business questions.
- **Interactive UI/UX Reporting:** Build a dynamic executive dashboard allowing stakeholders to drill down into specifics instantly.

## ech Stack & Skills Applied
- **Core Platform:** Microsoft Excel.
- **Advanced Formulas:** Utilized `XLOOKUP` with absolute cell referencing (`%`) to perform cross-sheet relational data merging (mapping custom Regional Bonus Discounts from a secondary reference table).
- **Data Aggregation:** Engine powered by Advanced Pivot Tables using customized groupings and multi-level sorting (Largest to Smallest profit metrics).
- **Dynamic Visualization:** Built an executive-facing interface featuring:
  - *Stacked Column Charts* for multi-variable logistical breakdown.
  - *Sorted Bar Charts* for rapid Top 5 product diagnostic ranking.
  - *Donut Charts* for regional revenue share comparison.
- **Interactivity:** Implemented global **Slicers** configured with **Report Connections** to enable synchronized, multi-chart dynamic filtering.

## Key Business Insights Derived
By leverage descriptive statistics and analytical reasoning on the `SampleSuperstore.csv` dataset, the following insights were uncovered:
1. **Regional Dominance:** The **West** region stands out as the primary engine for gross revenue, followed closely by the East.
2. **Logistical Preferences:** The **Consumer** segment represents the highest transaction volume, with a heavy operational reliance on *Standard Class* shipping fulfillment.
3. **Profitability Sweet Spots:** While certain categories command large sales numbers, sub-categories such as **Copiers** and **Phones** generate vastly superior net profit margins, indicating where future inventory allocation should be prioritized.
